# 03 指标口径

## 订单量
符合筛选条件的订单唯一数量：`COUNT(DISTINCT order_id)`。若宽表已验证订单唯一，可使用 `COUNT(*)`。

## 商品金额、支付金额、GMV
- 商品金额：`order_items.price` 按订单聚合后求和。
- 支付金额：`order_payments.payment_value` 按订单聚合后求和。
- GMV 必须明确字段定义和订单状态范围；不可默认商品金额等于支付金额。需说明取消、未付款等订单是否纳入。

## 运费
`freight_value` 先按订单聚合，再按维度求和；与商品金额分开解释。

## 配送评估口径
可评估订单：实际送达时间和预计送达时间都非空。准时：实际送达时间 <= 预计送达时间；延迟：实际送达时间 > 预计送达时间。准时率/延迟率分别为准时/延迟订单数除以可评估订单数。未送达和时间缺失订单单独统计。

## 延迟天数与区间
`DATEDIFF(actual, estimated)` 计算日历日期差，不是精确小时差。推荐互斥区间：`1 <= d < 3`、`3 <= d <= 7`、`d > 7`。0 天、负值和不可评估订单不进入正延迟区间。

## 月度与地区
按下单月份归属配送结果，表示该月下单订单的最终配送表现，不代表该月实际完成配送量。地区延迟率 = 地区延迟订单数 / 地区可评估配送订单数；比较时展示样本量。

## 校验清单
1. 宽表订单 ID 唯一。
2. 月度订单数合计与同口径订单数一致。
3. 准时数 + 延迟数 = 可评估订单数。
4. 延迟区间合计与区间覆盖的延迟订单数一致。
5. 汇总表与宽表重新聚合结果一致。
